## 二、核心架构对比

## 八、风险提示

| 项目 | 关键风险 | 缓解措施 |
|------|---------|---------|
| **HexStrike AI** | 存在路径遍历(#135)和远程代码执行(#124)漏洞 | **必须在隔离虚拟机中运行**，永不连接生产环境 |
| **Pentest Swarm AI** | AGPL-3.0许可证，商业使用可能需开源衍生作品 | 商用前需法务评估，或选择其他项目 |
| **RedAmon** | API Token成本高，长时间任务可能消耗大量费用 | 使用本地模型(Ollama)降低费用 |
| **所有项目** | Agent可能偏离预期路径，造成非授权操作 | 始终在授权靶场/测试环境使用，启用确认门 |
